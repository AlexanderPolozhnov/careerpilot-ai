# Task: AI Chat / Copilot UI (Плавающий виджет AI)

## Контекст и цель

Сделать функционал AI более доступным и интерактивным. Сейчас AI вызывается только со страницы деталей вакансии через статичную кнопку.
Необходимо добавить глобальный плавающий виджет (Copilot), который открывается в виде боковой панели (Slide-over) поверх текущего контента.
Из этого виджета пользователь сможет выбрать нужный инструмент (Сгенерировать Cover Letter, Подготовиться к интервью, Проанализировать вакансию) и быстро получить результат, не покидая текущую страницу (например, находясь на Kanban-доске).

## Затрагиваемые файлы

### Создать новые
- `frontend/src/context/CopilotContext.tsx` — глобальный стейт виджета (открыт/закрыт, выбранный контекст: vacancyId).
- `frontend/src/components/copilot/CopilotWidget.tsx` — плавающая кнопка (FAB).
- `frontend/src/components/copilot/CopilotDrawer.tsx` — сама боковая панель с интерфейсом чата/инструментов.
- `docs/tasks/new_tasks/TASK_COPILOT_UI.md` (этот файл)

### Изменить существующие
- `frontend/src/App.tsx` — обернуть приложение в `CopilotProvider` и добавить `CopilotWidget` в корень.
- `frontend/src/pages/ApplicationsPage.tsx` — опционально: добавить на карточки кнопку "Ask Copilot", которая открывает виджет с предзаполненным `vacancyId`.

## Точная реализация (Frontend)

Задача полностью фронтендовая, так как использует уже существующие эндпоинты `/ai/analyze-vacancy`, `/ai/cover-letter` и т.д.

### 1. CopilotContext

Создать контекст, который управляет видимостью панели:
```tsx
interface CopilotContextType {
  isOpen: boolean;
  openCopilot: (context?: { vacancyId?: string, resumeId?: string }) => void;
  closeCopilot: () => void;
  contextData: { vacancyId?: string, resumeId?: string } | null;
}
```

### 2. CopilotWidget (FAB)

Плавающая кнопка в правом нижнем углу экрана (фиксированная позиция `fixed bottom-6 right-6 z-40`).
Кнопка должна быть красивой, с иконкой `SparklesIcon` (звездочки), легкой анимацией `animate-pulse` (или кастомным glow-эффектом) и градиентным фоном.
При клике вызывает `openCopilot()`.

### 3. CopilotDrawer

Панель, выезжающая справа (`fixed inset-y-0 right-0 w-96 bg-surface-1 border-l border-border z-50 transform transition-transform`).

**Интерфейс панели:**
1. **Шапка:** Заголовок "CareerPilot AI", кнопка закрытия.
2. **Выбор контекста (Context Selector):**
   - Если `contextData.vacancyId` не передан, показать `<select>` или `<Command>` (комбобокс) для выбора вакансии (использовать `vacancyService.list`).
3. **Список действий (Actions):**
   Кнопки-карточки (как в командном меню):
   - 📄 Generate Cover Letter
   - 🎯 Match with Resume
   - 🗣️ Prepare Interview Questions
   - 📊 Analyze Vacancy
4. **Окно результатов (Chat/Result View):**
   - При клике на действие показывается лоадер (`isPending`).
   - Затем результат рендерится через `MarkdownViewer` (из предыдущей задачи) прямо в панели.
   - Добавить кнопку "Copy to clipboard".

### 4. Внедрение

В `App.tsx`:
```tsx
<CopilotProvider>
  <RouterProvider router={router} />
  <CopilotWidget />
  <CopilotDrawer />
</CopilotProvider>
```

## Порядок реализации для агента

1. Создать `CopilotContext.tsx`.
2. Создать компоненты виджета и боковой панели.
3. Добавить логику вызова `aiService` методов внутри панели, обработку загрузки (скелетоны или спиннер) и обработку ошибок.
4. Добавить селектор вакансии (если контекст пустой, AI не знает, для чего генерировать данные).
5. Использовать `MarkdownViewer` для отображения ответов.
6. Подключить виджет в `App.tsx`.
7. Запустить `npm run build` для проверки.
8. Выполнить все действия и синхронизировать все файлы которые описаны в последнем блоке этого файла.

## Риски и что проверить

- **Z-Index:** Убедиться, что `CopilotDrawer` имеет `z-index` выше, чем модалки отклика (`ApplicationTimelineModal`) и Topbar.
- **Мобильная адаптация:** Боковая панель должна на мобильных устройствах занимать 100% ширины (`w-full sm:w-96`).
- **Стейт:** При закрытии и повторном открытии панели результаты могут сбрасываться (что нормально) или сохраняться (опционально, требует хранения массива сообщений/результатов в стейте). Лучше начать со сбрасываемого стейта.

## Проверки после реализации

**Frontend:** `cd frontend && npm run build`
**Manual Smoke:**
1. Нажать на плавающую кнопку AI в углу экрана.

3. Выбрать вакансию из выпадающего списка (если не была передана).
4. Нажать "Generate Cover Letter" (или Analyze).
5. Дождаться результата и убедиться, что markdown отрендерен корректно и текст можно скопировать.
