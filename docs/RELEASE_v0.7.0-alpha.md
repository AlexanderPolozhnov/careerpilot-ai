# Release v0.7.0-alpha — Advanced AI & Stability

**Тег:** `v0.7.0-alpha`
**Статус:** Pre-release
**Дата:** 2026-05-22

## Обзор
Этот релиз знаменует собой переход к более качественной работе с ИИ и завершение формирования надежного фундамента автоматизации тестирования. Мы полностью переработали систему промптов, внедрили рендеринг Markdown и обеспечили стабильность CI/CD пайплайнов через полноценное покрытие тестами обоих слоев приложения.

## Ключевые изменения

### 🧠 Advanced AI & Resume Generation
- **Генерация резюме:** Добавлен новый инструмент для создания и адаптации резюме под требования конкретной вакансии.
- **Expert Prompts:** Системные промпты вынесены в отдельные Markdown-файлы и переработаны с использованием экспертных ролей (Recruiter, ATS Specialist, Career Coach).
- **Markdown UI:** Ответы ИИ теперь отображаются с полноценным форматированием (заголовки, списки, выделения) благодаря интеграции `react-markdown`.
- **Локализация промптов:** ИИ теперь отвечает на языке пользователя (RU/EN), используя соответствующие шаблоны промптов.

### 🧪 Тестирование и Стабильность (v0.6.0 Legacy)
- **Frontend Testing:** Развернута среда Vitest + React Testing Library. Добавлены тесты для критических сервисов (Auth, Vacancy) и базовых компонентов.
- **Backend Integration:** Стабилизированы тесты с Testcontainers (Postgres, Redis). Исправлены конфликты с асинхронностью и планировщиком в тестовом окружении.
- **CI/CD Hardening:** GitHub Actions теперь выполняет полный цикл проверок (Lint + Tests + Build) для каждого Pull Request.

### ⚡ Производительность и UX
- **Code Splitting:** Внедрена ленивая загрузка страниц (`React.lazy`), что значительно уменьшило размер начального бандла и ускорило первую загрузку.
- **Global Search (Cmd+K):** Реализована единая система поиска по всем сущностям проекта (вакансии, компании, задачи, интервью) с быстрым доступом через горячие клавиши.
- **Custom Scrollbar:** Добавлен стилизованный тонкий скроллбар в фирменных фиолетовых тонах проекта для всех платформ.
- **OAuth2 Polish:** Улучшена обработка ошибок при входе через социальные сети, добавлена валидация токенов и retry-логика.

### 🎨 Дизайн и Визуализация
- **Timeline:** Добавлена визуализация истории изменения статусов отклика с мгновенными тултипами.
- **Dashboard Polish:** Оптимизированы виджеты инсайтов и задач — теперь они имеют фиксированную высоту и аккуратный скрытый скролл.
- **Design System:** Расширена библиотека `ds-*` классов для обеспечения консистентности анимаций и карточек по всему приложению.

## Технические улучшения
- **Docker Compose:** Полностью готов full-stack конфиг для запуска всего окружения одной командой.
- **Vite Optimization:** Настроено ручное разделение чанков (manualChunks) для эффективного кэширования вендорных библиотек.
- **Audit Trail:** Реализовано логирование критических действий пользователей на уровне базы данных.
