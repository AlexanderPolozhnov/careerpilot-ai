# Release v0.5.0-alpha — Observability & Quality Hardening

**Тег:** `v0.5.0-alpha`
**Статус:** Pre-release
**Дата:** 2026-05-21

## Обзор
Этот релиз фокусируется на наблюдаемости (observability) системы, надежности фоновых процессов и общем качестве кодовой базы. Мы внедрили мониторинг AI-запросов, систему запланированных уведомлений и устранили критические ошибки, блокировавшие CI/CD.

## Ключевые изменения

### 📊 AI Observability & UX
- **Сбор метрик:** Теперь для каждого AI-запроса отслеживаются время выполнения (latency), количество использованных токенов и детали ошибок.
- **Улучшенный селектор:** В AI-ассистенте ручной ввод ID вакансии заменен на удобный выпадающий список с автозаполнением описания.
- **Мгновенная история:** Генерация новых AI-ответов теперь сразу обновляет список истории без перезагрузки страницы.

### 🔔 Уведомления и автоматизация
- **Scheduled Reminders:** Запущен фоновый процесс, который за 24 часа напоминает о собеседованиях и дедлайнах задач (через In-app и Email).
- **Динамический счетчик:** Иконка колокольчика в шапке теперь показывает реальное количество непрочитанных уведомлений.
- **Связанные сущности:** Уведомления теперь жестко связаны с объектами через `reference_id`, что позволяет переходить к задаче или интервью прямо из уведомления.

### 🔒 Security & Stability
- **Безопасное удаление:** Реализован процесс удаления аккаунта с подтверждением пароля и Email.
- **Управление паролями:** Пользователи, зашедшие через Google/GitHub, теперь могут создать локальный пароль для входа по Email.
- **CI/CD Fixes:** Устранены ошибки типизации TypeScript в `AuthContext` и обновлены Unit-тесты планировщика, что восстановило работоспособность пайплайнов.

### 🛠 Управление вакансиями
- **Архивация:** Добавлен функционал перевода вакансий в архив и их восстановления.
- **Визуальный стиль:** Архивные вакансии теперь визуально "приглушены" в списке для лучшего фокуса на активных позициях.
- **Поддержка тегов:** Реализован удобный ввод навыков (тегов) через запятую, которые сразу учитываются в аналитике Skill Gaps.

## Технические улучшения
- **Backend:** Исправлены ошибки `LazyInitializationException` в модуле аналитики и оптимизированы N+1 запросы через `@EntityGraph`.
- **Frontend:** Полностью устранены ошибки ESLint и предупреждения React о "set-state-in-render".
- **Дизайн:** Приведены к единому стилю тулбары и заголовки на страницах Вакансий, Задач и Собеседований.
