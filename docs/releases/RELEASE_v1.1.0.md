# Release v1.1.0 — AI Configuration & Stability Update

**Тег:** `v1.1.0`
**Статус:** Stable
**Дата:** 2026-06-07

## Обзор
Релиз v1.1.0 сфокусирован на полировке пользовательского опыта и стабильности работы с AI-провайдерами. Мы добавили полноценное тестирование соединения и синхронизацию моделей непосредственно со страницы настроек, устранили баги с наложением интерфейсов и внедрили прозрачную обратную связь через Toasts-уведомления.

## Ключевые изменения

### 🚀 Новые функции (Features)
- **Тестирование соединения ИИ:** Добавлена возможность проверять валидность API ключей для OpenAI, Gemini и Ollama прямо из интерфейса перед их сохранением.
- **Синхронизация моделей:** Автоматическая подгрузка доступных моделей по введенному API ключу с выводом автодополнения.
- **Система уведомлений (Toasts):** Внедрены мгновенные всплывающие сообщения об успешном или ошибочном сохранении конфигурации AI и пользовательских настроек.

### 🛠 Улучшения и оптимизация (Improvements)
- **CustomCombobox UX:** Исправлена проблема фильтрации — теперь при клике на выпадающий список отображаются все доступные элементы, а не только первый отфильтрованный.
- **Исправление Stacking Context (z-index):** Решена проблема перекрытия интерфейсов на странице настроек, где выпадающий список провайдеров прятался под соседним блоком "Уведомления".

### 🧪 Стабильность и тесты (Stability)
- **AI Key Validation:** Устранено ложное "Успешное" сообщение при тестировании с пустыми ключами. Теперь бэкенд строго валидирует доступность провайдера и выбрасывает корректные исключения, которые перехватываются и отображаются на UI.

## Технические детали
- **Backend:** 
  - Расширен контракт `LlmProvider` методом `getAvailableModels()`. 
  - Реализованы эндпоинты `POST /ai/test-connection` и `POST /ai/models/sync`.
  - Внедрены новые DTO `AiProviderConfigRequest` и `AiTestConnectionResponse`. 
  - Улучшена логика выброса исключений в `GeminiLlmProvider`, `OpenAiLlmProvider` и `OllamaLlmProvider`.
- **Frontend:** 
  - Обновлен `ai.service.ts` для работы с новыми эндпоинтами тестирования и синхронизации.
  - В `SettingsPage.tsx` добавлена интеграция с `toast.success` / `toast.error` с поддержкой i18n (`ru.json`, `en.json`).
  - Добавлена поддержка `<datalist>` для автозаполнения списка моделей.
- **Infra:** Версии пакетов в `pom.xml` и `package.json` синхронизированы до `1.1.0`.

## Что дальше?
- Реализация поддержки файлов (PDF/DOCX) для загрузки резюме напрямую (извлечение текста для AI).
- Интеграция Cloudflare для защиты от DDoS и WAF.
- Redis в production через GCP Memorystore + VPC Connector (для кэширования ответов AI).
