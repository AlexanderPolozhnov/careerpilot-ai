# Release v0.9.0-alpha — Telegram Notifications & UI State Sync

**Тег:** `v0.9.0-alpha`
**Статус:** Pre-release
**Дата:** 2026-05-24

## Обзор
В этом релизе мы сфокусировались на расширении каналов уведомлений и повышении надежности пользовательского интерфейса. Главным нововведением стала полноценная интеграция Telegram-бота, который теперь может отправлять напоминания о предстоящих собеседованиях, дедлайнах задач и изменениях статусов откликов. Также мы серьезно доработали механизм синхронизации состояния между бэкендом и фронтендом при выполнении внешних действий (например, подтверждение привязки бота через браузер).

## Ключевые изменения

### 🚀 Новые функции (Features)
- **Telegram Notifications:** Добавлена интеграция с Telegram через бота. Пользователи могут привязать свой аккаунт CareerPilot AI к Telegram в настройках (раздел Notifications) с помощью специального токена (deep link: `/start {token}`). Бот отправляет HTML-форматированные сообщения и поддерживает команду `/help`.
- **Автоматические уведомления об откликах:** Теперь система умеет отправлять In-app и Email/Telegram уведомления при изменении статуса отклика (например, переход на этап `TECH_INTERVIEW`), исключая черновые `SAVED` статусы.

### 🛠 Улучшения и оптимизация (Improvements)
- **Strategy/Factory Pattern для уведомлений:** Архитектура отправки сообщений была переработана. Внедрен фабричный паттерн (`NotificationSenderFactory`), который динамически выбирает нужного провайдера (`EmailNotificationSender` или `TelegramNotificationSender`) на основе настроек пользователя в `PreferencesEntity`.
- **Синхронизация состояния UI (Fail-safe Sync):** Исправлена проблема, когда после привязки Telegram-бота переключатель (radio button) в настройках оставался на "Почте". Теперь фронтенд обходит кэш React Query (через прямой запрос) и принудительно обновляет форму при нажатии кнопки "Готово".
- **Надежное переключение настроек:** Бэкенд получил механизм автоматического переключения `notificationProvider` на `TELEGRAM` сразу после того, как пользователь активирует бота в мессенджере. Это гарантирует правильные настройки даже если пользователь закроет вкладку с сайтом до подтверждения.
- **CustomSelect во всех фильтрах:** Нативные теги `<select>` в фильтрах на страницах Vacancies, Tasks и Interviews окончательно заменены на новый стилизованный компонент `CustomSelect` с поддержкой цветных индикаторов приоритета.

### 🧪 Стабильность и тесты (Stability)
- **TelegramBotsApi Registration:** Устранена критическая архитектурная проблема: базовая библиотека `org.telegram:telegrambots` не регистрирует Spring-бины автоматически. Создан выделенный конфигурационный класс `TelegramConfig` с явным вызовом `api.registerBot()`, что обеспечило стабильную работу Long Polling соединения.
- **Null-checks в фильтрах:** В сервисный слой бэкенда добавлена проверка `if (request.field() != null)`, чтобы предотвратить ошибки 500 при отправке пустых значений фильтров от нового компонента `CustomSelect`.

### 🔒 Безопасность (Security)
- **Защита Telegram токенов:** Токены привязки генерируются как уникальные UUID и удаляются из базы данных (устанавливаются в `null`) сразу после успешной привязки чата, предотвращая возможность перехвата или повторного использования.

## Технические детали
- **Backend:** 
  - Новые зависимости: `org.telegram:telegrambots:6.9.0`.
  - Flyway-миграция `V28__add_telegram_provider.sql` добавила колонки `notification_provider`, `telegram_chat_id` и `telegram_connect_token` в таблицу `user_preferences`.
  - Новый интерфейс `NotificationSender` и классы `TelegramBotHandler`, `TelegramConfig`.
- **Frontend:** 
  - Обновлен `settings.service.ts` и `SettingsPage.tsx` для поддержки нового типа провайдера `TELEGRAM`.
  - Добавлены новые локализационные ключи в `ru.json` и `en.json` для инструкций по подключению Telegram.
- **Infra:** 
  - В файл окружения (`.env`) добавлены новые флаги: `TELEGRAM_BOT_ENABLED`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME`.
