# Инструкция по регистрации приложения OAuth2 на HeadHunter (hh.ru)

Этот документ содержит пошаговое руководство по созданию и настройке разработческого приложения на портале **developer.hh.ru** для интеграции с CareerPilot AI.

---

## 🛠️ Шаг 1: Авторизация на hh.ru
1. Перейдите на официальный портал для разработчиков: [https://dev.hh.ru/](https://dev.hh.ru/) (или [https://developer.hh.ru/](https://developer.hh.ru/)).
2. Нажмите кнопку **«Войти»** в правом верхнем углу.
3. Авторизуйтесь под своим аккаунтом соискателя (или работодателя). 

> [!NOTE]
> Рекомендуется использовать аккаунт, на котором уже заполнено реальное резюме, чтобы вы могли протестировать API-запросы сразу после регистрации.

---

## 📝 Шаг 2: Создание приложения
1. После входа перейдите в раздел **«Мои приложения»** (или нажмите кнопку **«Зарегистрировать новое приложение»**).
2. Заполните форму создания приложения:

| Поле | Что указывать | Примечание |
|---|---|---|
| **Название приложения** | `CareerPilot AI` (или `HH Помощник`) | Это название будут видеть пользователи в окне подтверждения доступа. |
| **Краткое описание** | `Интеллектуальный ассистент для умного поиска вакансий, авто-откликов и ИИ-подготовки к собеседованиям.` | Должно быть написано грамотно, иначе модерация отклонит заявку. |
| **Сайт приложения** | `https://careerpilot-ai.ru` | Основной домен вашего проекта. |
| **Redirect URI (Callback URL)** | `https://careerpilot-ai.ru/api/integration/hh/callback` | **КРИТИЧНО!** Сюда hh.ru отправит код авторизации. Для локальной разработки добавьте также `http://localhost:8080/api/integration/hh/callback`. |

---

## 🔐 Шаг 3: Получение ключей авторизации
После сохранения приложения (оно создается в режиме «Песочницы» / Sandbox) вам будут предоставлены ключи:
* **Client ID** (Идентификатор клиента)
* **Client Secret** (Секретный ключ клиента)

Скопируйте их и добавьте в `.env` вашего бэкенда:
```env
HH_CLIENT_ID=ваш_client_id
HH_CLIENT_SECRET=ваш_client_secret
HH_REDIRECT_URI=https://careerpilot-ai.ru/api/integration/hh/callback
```

---

## 🛡️ Шаг 4: Прохождение модерации (для Production)
Приложение в режиме Sandbox имеет ограничения (доступ только для вашего аккаунта). Чтобы разрешить логин другим пользователям, нужно отправить приложение на модерацию:
1. В карточке приложения нажмите кнопку **«Отправить на модерацию»**.
2. В поле обоснования напишите профессиональный текст. Примерный шаблон:
   > *«Уважаемая поддержка hh.ru! Данное приложение является персональным ассистентом соискателя (CareerPilot AI). Интеграция с API необходима для того, чтобы пользователи могли бесшовно авторизоваться через свой аккаунт hh.ru, синхронизировать свои резюме (желаемая должность, навыки, локация) со своим профилем в нашей системе для точной фильтрации вакансий и подготовки к собеседованиям с помощью ИИ. Мы не занимаемся спамом вакансий и строго соблюдаем ограничения на частоту запросов (rate limits). Просим одобрить наше приложение.»*
3. Модерация обычно занимает **от 1 до 3 рабочих дней**.

---

## ⚙️ Доступные Scopes (Права)
По умолчанию для базовых интеграций достаточно прав:
* `read_responses` — чтение откликов пользователя.
* `write_responses` — отправка откликов (сопроводительных писем).
* `read_resumes` — чтение резюме пользователя для синхронизации профиля.
* `write_resumes` — возможность обновлять резюме (опционально).
* `read_vacancies` — поиск вакансий.
