# MCP Guide — CareerPilot AI

Руководство по использованию MCP-серверов (GitHub, PostgreSQL, Redis) в Windsurf Cascade.

---

## Предварительные условия

Перед работой с MCP убедись, что локальное окружение запущено:

```bash
docker compose up -d postgres redis
```

Статус MCP-серверов: **Windsurf → Settings → MCP** — все три должны быть ✅.

## GitHub MCP

### Issues

```
Создай issue с заголовком "..." и описанием "..."
Покажи все открытые issues в репозитории

```

```

```


## Troubleshooting

| Проблема | Решение |
|----------|---------|
| MCP сервер показывает ❌ | Перезапусти Windsurf |
| PostgreSQL: connection refused | `docker compose up -d postgres` |
| Redis: connection refused | `docker compose up -d redis` |
| GitHub: unauthorized | Проверь PAT в `mcp_config.json` — не истёк ли токен |
| npx: package not found | Проверь наличие Node.js: `node -v` |

Путь к конфигу MCP: `C:\Users\Александр\.codeium\windsurf\mcp_config.json`
