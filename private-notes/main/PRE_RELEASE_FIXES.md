# CareerPilot AI — Пред-релизные правки

Документ фиксирует баги, UX-проблемы и незавершённые зоны, выявленные при ручном тестировании перед релизом
`v0.1.0-alpha`.

## Legend

- `[P1]` — блокер релиза: сломано или вводит в заблуждение
- `[P2]` — важно для качества: заметно, мешает, но не блокирует
- `[P3]` — улучшение: хорошо бы, но можно после релиза

---

## 1. AI Assistant

### ✅ [P1] Неинформативное сообщение об ошибке валидации

**Страница:** AI Assistant  
**Проблема:** При вводе короткого текста появляется общее "Пожалуйста, исправьте выделенные поля" без пояснения, какое
именно ограничение нарушено (минимальная длина, обязательное поле и т.д.).  
**Ожидаемо:** Конкретное сообщение рядом с полем, например "Минимум 50 символов" или "Поле обязательно".  
**Файлы:** `AiAssistantPage.tsx`, форма валидации (Zod schema).

---

## 2. Analytics

### ✅ [P1] Mock данные в блоке "Пробелы в навыках"

**Страница:** Analytics  
**Проблема:** Блок "Пробелы в навыках / Наиболее частые недостающие требования" показывает захардкоженные mock данные
вместо данных из `GET /api/analytics/summary` → поле `topSkillGaps`.  
**Ожидаемо:** Реальные данные из backend или пустое состояние если данных нет.  
**Файлы:** `AnalyticsPage.tsx`, `analytics.service.ts`.

### [P2] Нет перевода "Week" в блоке "Активность за неделю"

**Страница:** Analytics  
**Проблема:** В блоке "Активность за неделю" метки оси X остаются на английском "Week 1", "Week 2" и т.д. без
перевода.  
**Ожидаемо:** "Неделя 1", "Неделя 2" при выбранном русском языке.  
**Файлы:** `AnalyticsPage.tsx`, `ru.json`.

### [P2] Отклик отображается в неправильной неделе

**Страница:** Analytics  
**Проблема:** Единственный отклик отображается в "Week 3" вместо "Week 1" — вероятно, неправильная логика группировки по
неделям на backend или некорректный расчёт номера недели.  
**Файлы:** `AnalyticsServiceImpl.java` — метод построения `weeklyActivity`.

## 3. Dashboard

### [P2] Неактивный блок аккаунта / настроек справа сверху

**Страница:** Dashboard (header)  
**Проблема:** Кнопка/аватар пользователя в правом верхнем углу не работает — нет dropdown меню с переходом в Settings,
Logout и т.д.  
**Ожидаемо:** Dropdown с пунктами: Профиль → `/settings`, Выйти → logout.  
**Файлы:** `AppLayout.tsx` или `Header.tsx`, `AuthContext.tsx`.

---

## 4. Глобальный поиск в header

### [P3] Непонятное назначение верхнего поиска

**Страница:** Все страницы (header)  
**Проблема:** Есть глобальный поиск в шапке, но на страницах Вакансии и Компании уже есть свой поиск. Назначение
глобального поиска непонятно пользователю.  
**Варианты решения:**

- Убрать глобальный поиск из header до реализации полноценного глобального поиска
- Добавить placeholder "Поиск по вакансиям, компаниям..." и реализовать реальную логику
- Скрыть до следующего релиза  
  **Файлы:** `AppLayout.tsx` или `Header.tsx`.

---

## 5. Sidebar — блок "Совет"

### [P3] Mock совет не зависит от страницы

**Страница:** Все страницы (sidebar)  
**Проблема:** Блок "Совет" в левой панели навигации показывает один и тот же статичный текст вне зависимости от текущей
страницы. Выглядит незаконченно.  
**Варианты решения:**

- Убрать блок до реализации реальной логики
- Показывать советы в зависимости от текущего маршрута (статичный mapping route → совет)  
  **Файлы:** `Sidebar.tsx` или `AppLayout.tsx`.

---

## 6. Вакансии — создание и редактирование

### ✅ [P1] Форма создания вакансии неполная

**Страница:** Vacancies  
**Проблема:** При нажатии "Добавить вакансию" открывается диалог только с полем "Название вакансии". Остальные поля (
компания, локация, тип занятости, зарплата и т.д.) недоступны.  
**Ожидаемо:** Полная форма создания вакансии согласно `CreateVacancyDto` из контракта.  
**Файлы:** `VacanciesPage.tsx`, форма создания вакансии.

### ✅ [P1] Редактирование вакансии только по названию

**Страница:** Vacancy Detail  
**Проблема:** Кнопка "Редактировать название" позволяет изменить только title. Нет возможности редактировать остальные
поля.  
**Ожидаемо:** Кнопка "Редактировать" открывает полную форму редактирования (те же поля что и при создании,
предзаполненные текущими значениями).  
**Файлы:** `VacancyDetailPage.tsx`.

### ✅ [P1] Двойной toast при удалении вакансии + неверный текст

**Страница:** Vacancy Detail  
**Проблема:** При удалении вакансии появляется два toast-сообщения. Текст "Vacancy not found" — неверный (должно быть "
Вакансия удалена"). Белый текст на белом фоне — не читается.  
**Ожидаемо:** Один toast "Вакансия успешно удалена" с корректным цветом текста, затем редирект на список вакансий.  
**Файлы:** `VacancyDetailPage.tsx`, `Toast.tsx`, `ru.json` / `en.json`.

## 7. Вакансии — кнопки действий

### [P2] Неверные названия кнопок "Сохранить" и "Применить"

**Страница:** Vacancy Detail  
**Проблема:**

- "Сохранить" → лучше "В избранное" (добавляет в статус `SAVED`)
- "Применить" → лучше "Откликнуться" (добавляет в статус `APPLIED`)
- Статус "Новое" (`NEW`) нельзя назначить через UI, только перетаскиванием на Kanban — непонятно зачем он вообще есть
  как отдельный статус в этом контексте  
  **Файлы:** `VacancyDetailPage.tsx`, `ru.json` / `en.json`.

---

## 8. Компании

### [P1] Нет возможности создать компанию

**Страница:** Companies  
**Проблема:** На странице компаний отсутствует кнопка создания компании. Backend endpoint `POST /api/companies`
реализован, но UI не предоставляет форму.  
**Ожидаемо:** Кнопка "Добавить компанию" с формой (name, website, industry, size, location).  
**Файлы:** `CompaniesPage.tsx`.

---

## 9. AI Assistant — история анализов

### [P2] Новый анализ перезаписывает предыдущий

**Страница:** Vacancy Detail → AI аналитика  
**Проблема:** При повторной генерации AI анализа новый результат заменяет предыдущий в правой панели вместо добавления в
список.  
**Ожидаемо:** Список анализов с возможностью просматривать историю. При клике на анализ — подсветка, возможность
удалить.

### [P2] Лишняя кнопка "Сгенерировать" в панели AI аналитики

**Страница:** Vacancy Detail → AI аналитика  
**Проблема:** В правой панели AI аналитики есть дополнительная кнопка "Сгенерировать" назначение которой неочевидно.  
**Ожидаемо:** Убрать дублирующую кнопку. Вместо неё — при клике на карточку анализа показывать опции (просмотр,
удаление).  
**Файлы:** `VacancyDetailPage.tsx`.
