# 🎯 CareerPilot AI — Пользовательский Journey

## Обзор

После регистрации пользователь попадает в многоуровневую систему управления поиском работы. Первый день интенсивен: настройка профиля, импорт данных, знакомство с AI-ассистентом.

**Ключевое различие:**
- **Без оплаты подписки** → Доступны базовые функции (управление вакансиями, отслеживание откликов)
- **С оплатой подписки** → Разблокируются AI-функции (анализ вакансий, cover letter, подготовка к интервью)

---

## ЭТАП 1: РЕГИСТРАЦИЯ И ПЕРВЫЙ ВХОД (5-10 мин)

### Шаг 1.1: Регистрация
**Экран:** `AuthPages.tsx` (mode: 'register')
```
┌─────────────────────────────┐
│ Создать аккаунт             │
│ Начните управлять поиском   │
├─────────────────────────────┤
│ ФИ: Alexander               │
│ Email: alex@company.com     │
│ Пароль: ••••••••            │
│ Повтор: ••••••••            │
│ [Зарегистрироваться]        │
└─────────────────────────────┘
```

**Действие пользователя:**
1. Вводит имя, email, пароль (минимум 8 символов)
2. Нажимает "Зарегистрироваться"
3. Backend сохраняет пользователя в PostgreSQL
4. JWT token создается и сохраняется в localStorage

**Результат:** Пользователь авторизован, перенаправляется на `/app/dashboard`

**Экран:** `SettingsPage.tsx`
```
┌─────────────────────────────────────────────────────────┐
│ 🔧 Settings                                             │
├──────────────────────────────────────────────────────────┤
│ 👤 ПРОФИЛЬ              │ 🤖 AI ПРОВАЙДЕР              │
│ ┌─────────────────────┐ │ ┌──────────────────────────┐ │
│ │ ФИ: Alexander       │ │ │ Режим AI:                │ │
│ │ Email: alex@c.com   │ │ │ ⚪ CLOUD (платный)      │ │
│ │ Локация: Remote     │ │ │ ⚫ LOCAL (бесплатный)    │ │
│ │                     │ │ │ ⚪ BRING_YOUR_OWN_KEY    │ │
│ │ [Сохранить]         │ │ │                          │ │
│ └─────────────────────┘ │ │                          │ │
│                         │ │ Текущий выбор:           │ │
│ 🔔 УВЕДОМЛЕНИЯ         │ │ CLOUD (нужна подписка)   │ │
│ ┌─────────────────────┐ │ └──────────────────────────┘ │
│ │ ☑️ Weekly Digest     │ │                              │
│ │ ☑️ Interview Reminders│                              │
│ └─────────────────────┘ │ 🗣️ ЯЗЫК                      │
│                         │ 🇷🇺 Русский (выбрано)       │
│ 🌐 ЯЗЫК                 │ 🇬🇧 English                  │
│ ┌─────────────────────┐ │                              │
│ │ 🇷🇺 Русский (✓)     │ │                              │
│ │ 🇬🇧 English         │ │                              │
│ └─────────────────────┘ │                              │
└──────────────────────────────────────────────────────────┘
```

**Действие пользователя:**
1. **Заполняет профиль:**
   - Проверяет имя и email
   - Вводит локацию (например, "Remote" или "Moscow, Russia")
   - Нажимает "Сохранить" → backend сохраняет в БД

2. **Выбирает AI провайдер:**
   - **CLOUD** → Платная подписка требуется (разблокирует все AI-функции)
   - **LOCAL** → Бесплатно, но медленнее (использует Ollama локально)
   - **BRING_YOUR_OWN_KEY** → Платный, но ключ пользователя

3. **Настраивает уведомления:**
   - ☑️ Weekly Digest (еженедельный отчет)
   - ☑️ Interview Reminders (напоминания о собеседованиях)

4. **Выбирает язык:**
   - Переключается между РУ/EN (сохраняется в localStorage)

**Результат:** Профиль готов к работе

## 📊 ТАБЛИЦА СТАТУСОВ ОТКЛИКОВ

| Статус | Что это | Кто обновляет | Как |
|--------|--------|---------------|-----|
| **NEW** | Новый отклик (сохранен, но не отправлен) | Пользователь | Вручную создает |
| **SAVED** | Отклик в черновиках (подготовка) | Пользователь | Вручную |
| **APPLIED** | ✅ Отклик отправлен | Пользователь | Вручную + пример: скопировал на LinkedIn |
| **HR_SCREEN** | HR просматривает CV | Пользователь / Система | Вручную или вебхук (если интеграция) |
| **TECH_INTERVIEW** | 🎤 Назначено техническое собеседование | Пользователь / Система | Вручную или вебхук |
| **FINAL_ROUND** | 🎯 Финальный раунд | Пользователь / Система | Вручную или вебхук |
| **OFFER** | 🎉 Получено предложение | Пользователь | Вручную |
| **REJECTED** | ❌ Отклонено | Пользователь / Система | Вручную |
